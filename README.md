## Ruescan: free site check

**[Ruescan](https://ruesandora.com/tools/site-check)** reads a site's home page, robots.txt, sitemap and llms.txt and measures mobile speed with Google PageSpeed. Findings in 6 areas: AI bots and access, sitemap and indexing, AI-ready content, structured data, meta and sharing, speed and security. Each AI bot is shown as allowed or blocked. No sign-up.

## How the work is done

- Research, content, code and competitor tracking go to AI agents built for the project.
- Every output is checked by a separate agent that did not write it; anything unsourced or wrong goes back.
- A person decides what goes live. Anything that cannot be verified is written as "could not be verified".
